Pythagoras Aufgabe 27

In einem rechtwinkligen Dreieck ist die Höhe das 
n-fache des Hypotenusenabschnitts q.  
Drücken Sie die Länge der Hypotenuse c durch n 
und q aus.    



c = p + q 

Höhensatz:

h2 = q * p 

h = n * q 

h2 = (n * q)2 = n2 * q2 

n2 * q2 = q * p | :q 

n2 * q = p 

In c = p + q eingesetzt:

c = n2 * q + q 

c = q(1 + n2)
